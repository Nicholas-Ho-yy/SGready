# SG Env Ready

A Flutter mobile app for **Singapore environmental preparedness** — combining live NEA data from [data.gov.sg](https://data.gov.sg) with actionable safety guidance and gamification (quizzes, checklists, points, badges).

Built for an FYP exploring whether alerts + guidance + gamification can improve preparedness for haze, UV, heat, and flash flood risks.

## Features

| Feature | Description |
|---------|-------------|
| **Live dashboard** | PSI (24h) by region, UV index, heavy rainfall detection |
| **Safety guidance** | Context-aware recommendations based on NEA thresholds |
| **Checklists** | Haze, UV, heat, and flood preparedness tasks |
| **Quizzes** | Singapore-specific knowledge with explanations |
| **Gamification** | Points, levels, badges, daily check-in streaks (Firebase) |
| **Push alerts** | Firebase Cloud Messaging (setup required) |

## Data sources (data.gov.sg)

| Data | API endpoint | Update frequency |
|------|--------------|------------------|
| PSI | `https://api-open.data.gov.sg/v2/real-time/api/psi` | Every 15 min |
| UV Index | `https://api-open.data.gov.sg/v2/real-time/api/uv` | Every 30 min |
| Rainfall | `https://api-open.data.gov.sg/v2/real-time/api/rainfall` | Every 5 min |

## Prerequisites

1. [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.16+)
2. Android Studio / Xcode for emulators
3. [Firebase project](https://console.firebase.google.com) (Auth, Firestore, FCM)

## Quick start

```bash
# From this folder — generates android/ and ios/ platform folders
flutter create . --project-name sg_env_ready --org com.sgenvready

flutter pub get
flutter run
```

The `lib/` source is already scaffolded. `flutter create .` adds platform files without overwriting `lib/main.dart` if you use the command above carefully — if prompted to overwrite, keep existing `lib/` files.

## Firebase setup

1. Create a Firebase project at [console.firebase.google.com](https://console.firebase.google.com)
2. Enable **Authentication** (Email/Password or Anonymous for prototyping)
3. Enable **Cloud Firestore**
4. Enable **Cloud Messaging**
5. Install FlutterFire CLI and configure:

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

This replaces `lib/firebase_options.dart` with your real credentials.

### Firestore structure

```
users/{uid}
  points: number
  streakDays: number
  completedChecklistIds: string[]
  completedQuizIds: string[]
  earnedBadgeIds: string[]
```

### Security rules (starter)

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

## FYP research angle

**Hypothesis:** A mobile app that combines real-time environmental data, plain-language action steps, and gamification increases user engagement with preparedness compared to passive information sources.

**Metrics you could measure:**
- Daily active usage / check-in rate
- Checklist completion rate
- Quiz scores over time
- User survey: self-reported preparedness confidence (pre/post)
